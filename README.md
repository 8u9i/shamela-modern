# المكتبة الشاملة الإباضية

تطبيق سطح مكتب حديث وعصري للمكتبة الشاملة الإباضية. يعمل على ويندوز، ماك، ولينكس.

---

## التحميل السريع

حمل أحدث إصدار من [صفحة الإصدارات](https://github.com/8u9i/shamela-modern/releases).

| النظام | الملف |
|--------|-------|
| ويندوز | `Al-Maktaba-Al-Shamela-Setup-1.0.2.exe` |
| ماك (Apple Silicon) | `Al-Maktaba-Al-Shamela-1.0.2-arm64.dmg` |
| لينكس (AppImage) | `Al-Maktaba-Al-Shamela-1.0.2.AppImage` |
| لينكس (deb) | `shamela-modern_1.0.2_amd64.deb` |

> 💡 بعد تثبيت الإصدار الأول، سيتحقق التطبيق تلقائياً من التحديثات الجديدة ويقوم بتحديث نفسه من داخل التطبيق — دون الحاجة لتحميل المثبت يدوياً.

---

## طريقة التثبيت

**ويندوز:** انقر نقراً مزدوجاً على ملف `.exe` واتبع خطوات المثبت.

**ماك:** افتح ملف `.dmg` واسحب التطبيق إلى مجلد التطبيقات.

**لينكس AppImage:** اجعل الملف قابلاً للتنفيذ (`chmod +x *.AppImage`) وشغّله.

**لينكس deb:** ثبّت عبر `sudo dpkg -i *.deb`.

## البناء من المصدر

للمطورين الراغبين في بناء التطبيق بأنفسهم:

```bash
# تثبيت الاعتماديات
npm install

# إعادة بناء better-sqlite3 لإلكترون
npx electron-rebuild -f -w better-sqlite3

# بناء الواجهة
npm run build

# تعبئة لمنصتك
npm run package:win    # ويندوز
npm run package:mac    # ماك
npm run package:linux  # لينكس

# تعبئة لجميع المنصات
npm run package:all
```

الملفات المعبأة ستكون في مجلد `dist-app/`.

### تشغيل التطوير

```bash
npm run dev
```

### تشغيل الاختبارات

```bash
npm run e2e         # بناء + اختبارات
npm run e2e:dev     # اختبارات فقط (دون بناء)
```
